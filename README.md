# SENTINEL

A procedural game engine and a mini Project I.G.I.-style infiltration game in Odin + OpenGL 4.1. No models, no image files: every mesh and texture is generated at runtime.

Run: `odin run Source -out:Sentinel`. Check everything: `Tools/CheckAll.sh`. Rules and commands: `CLAUDE.md`. Find any feature: `Docs/Features.md`.

Mission: enter the compound, hack the HQ computer, destroy the radar, rescue the hostage, reach the green beacon.

Controls: WASD move, mouse look, Shift run, C crouch, Space jump, left mouse fire, R reload, 1-5 weapons, F flashlight, E use (doors, hacking, rescue, vehicles), B binoculars, M map, Tab fly camera, Enter respawn, Esc quit. In vehicles: WASD drive, mouse aims the turret, V view; helicopter: Space/Ctrl climb and descend, Q/E strafe.
